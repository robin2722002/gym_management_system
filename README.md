# 🏋️ Gym Management System

A Django-based Gym Management System with role-based authentication and management features for Admin, Trainers, and Members.

---

# 🚀 Features

## 👨‍💼 Admin
- Manage and view trainers and members
- Dashboard management
- Manage bookings and workout plans

## 🏋️ Trainer
- Create and manage trainer profiles
- View assigned members
- Update schedules

## 👤 Member
- User registration & login
- View trainer profiles
- Book training sessions
- Manage personal dashboard
- book a trainer
- cancel booking
- forgot password
